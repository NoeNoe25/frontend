# Medist Frontend (upload copy)

A file-by-file upload of the React frontend for **Medist**, the Thai healthcare assistant built at the CMKL Hackathon.

> **Use [CMKL_Hackathon](https://github.com/NoeNoe25/CMKL_Hackathon) instead.** It contains the same frontend in a working project layout (`frontend/src/components/…`) together with the Flask backend and the RAG pipeline. In this repository the files are not in their `src/` folders, so the app does not build as-is.
